# CodeForge Project Collection

Seven interactive browser projects. Open `index.html` in a browser to browse the directory.

| Project | Description |
|---|---|
| [java-academy](projects/java-academy/) | Responsive HTML + CSS + JavaScript app |
| [devtools-hub](projects/devtools-hub/) | Responsive HTML + CSS + JavaScript app |
| [taskflow](projects/taskflow/) | Responsive HTML + CSS + JavaScript app |
| [budget-board](projects/budget-board/) | Responsive HTML + CSS + JavaScript app |
| [typing-sprint](projects/typing-sprint/) | Responsive HTML + CSS + JavaScript app |
| [focus-timer](projects/focus-timer/) | Responsive HTML + CSS + JavaScript app |
| [quiz-arena](projects/quiz-arena/) | Responsive HTML + CSS + JavaScript app |

All projects work locally without installation. Some save data to localStorage and are demos, not production backends.

For a hosted live demo, enable GitHub Pages from Settings → Pages → Deploy from main / (root).
