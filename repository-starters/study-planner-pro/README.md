# Study Planner Pro 📚

A self-contained English-language study planner that works in the browser.

## Features
- Create tasks with subjects, priorities and optional deadlines
- Mark tasks as completed
- Search, filter and sort tasks
- Live progress statistics
- Save tasks in localStorage on your device
- Delete individual tasks or clear finished tasks

## Run
Open `index.html` in a browser. Everything is static and works offline after first loading; the optional Google font needs internet to load.

## Deploy with GitHub Pages
In your new repository, open **Settings → Pages → Deploy from a branch**; select `main` and `/(root)`.

## Structure
- `index.html` — page markup
- `style.css` — visual design
- `script.js` — app logic
- `README.md` — guide

**Privacy notice:** Stored tasks remain in the same browser and may be lost when browser data is cleared. No cloud sync is included.
