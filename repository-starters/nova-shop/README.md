# NOVA Shop 🛍️

A responsive English-language **front-end e-commerce project** written in vanilla HTML, CSS and JavaScript.

## Features
- Searchable 9-product demo catalog
- Filter products by category
- Sort by ascending or descending price
- Add and remove items from cart
- Change item quantities and recalculate totals
- Persist the cart in localStorage
- Simulated checkout that saves a local order history

## Run
Open `index.html` in a browser or serve the directory with any static web server.

## GitHub Pages
In a standalone repository, open **Settings → Pages** and select **Deploy from a branch**, `main`, `/(root)`.

## Project files
- `index.html` — storefront markup
- `style.css` — shared styles
- `script.js` — search, filtering and cart operations
- `README.md` — documentation

**Important:** This is a front-end portfolio demo, not a live shop. Checkout does not accept money, place real orders or collect card information.
