# Three standalone repository starter projects

Each folder below contains a complete English-language website with `index.html`, `style.css`, `script.js` and `README.md`. Copy each folder's **contents** to the root of a separately created GitHub repository.

1. [Java Mastery Course](java-mastery-course/) — interactive Java course
2. [Study Planner Pro](study-planner-pro/) — task and deadline organizer
3. [NOVA Shop](nova-shop/) — demo shopping storefront

These are folders in the current repository, not separate GitHub repositories yet. Creating new repositories requires an additional GitHub action in the web UI. No existing files were deleted.
