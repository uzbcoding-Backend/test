# Java Mastery Course ☕

An interactive English-language Java learning website with ten beginner and intermediate lessons.

## Features
- 10 structured lessons and code examples
- Multiple-choice quizzes with immediate feedback
- Progress saved with browser localStorage
- Responsive dark-mode interface
- Copy code examples for use in a real Java compiler

## Run locally
Open `index.html` in any modern browser. No installation is necessary for the website.

To execute the **Java code**, install a JDK, save each suitable example to a `.java` file and compile it with `javac` / run it with `java`. The sample snippets in this course are educational and some are fragments rather than complete programs.

## Deploy
Host these static files using GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Project structure
- `index.html` — page layout
- `style.css` — responsive styling
- `script.js` — lessons and quiz interactions
- `README.md` — documentation

No credentials, payments or server required.
